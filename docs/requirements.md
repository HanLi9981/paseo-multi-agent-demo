## 1. 项目概述

一个单页待办事项（Todo）应用，当前以单个 `index.html` 文件承载全部 HTML、CSS 与 JavaScript，无构建步骤、无外部依赖、无后端服务。

## 2. 已知功能（可从现有代码确认）

以下行为均可在 `index.html` 中直接核对，属于**现状事实**，不是新增需求。

### 2.1 页面结构
| 编号 | 事实 | 代码位置 |
|---|---|---|
| F-01 | 页面标题为「待办事项」，`lang="zh-CN"`，含 viewport 声明 | `<head>` |
| F-02 | 主容器为 `.app` 卡片；含 `h1` 标题、`.input-row` 输入区、`.stats` 统计区、`ul#todo-list` 列表区 | `<body>` |
| F-03 | 输入框 `#todo-input`，placeholder「输入新的待办事项…」，`maxlength="200"` | `.input-row` |
| F-04 | 添加按钮 `#add-btn`，文案「添加」 | `.input-row` |
| F-05 | 统计区两个字段：`#stats-pending`「未完成：N」、`#stats-done`「已完成：N」 | `.stats` |
| F-06 | 空列表时渲染 `.empty` 提示「暂无待办事项，添加一条吧 ✨」 | `render()` |
| F-07 | 列表项 `li` 内含 `span.text` 与 `button.delete-btn`（文案「×」，`aria-label="删除"`）；已完成项加 `completed` 类 | `render()` |

### 2.2 交互行为
| 编号 | 事实 | 代码位置 |
|---|---|---|
| F-08 | 新增：取输入值 `trim()`；为空时仅聚焦输入框并短暂显示红色边框（约 1 秒），不新增条目 | `addTodo()` |
| F-09 | 新增成功：写入 `{ id: Date.now(), text, completed: false }`，清空输入框并重新聚焦，保存并重绘 | `addTodo()` |
| F-10 | 切换完成状态：点击列表项（非删除按钮区域）切换 `completed` | `toggleTodo()` + 列表点击委托 |
| F-11 | 删除：点击 `.delete-btn` 按 `id` 从数组移除 | `deleteTodo()` + 列表点击委托 |
| F-12 | 键盘：输入框内按 `Enter` 等价于点击「添加」 | `keydown` 监听 |
| F-13 | 页面加载时立即执行一次 `render()` | 脚本末尾 |

### 2.3 数据与渲染
| 编号 | 事实 | 代码位置 |
|---|---|---|
| F-14 | 数据持久化到 `localStorage`，键名 `todo-list-data` | `STORAGE_KEY` |
| F-15 | 读取时若 JSON 解析失败或结构非数组，回退为空数组（异常被吞掉，无用户提示） | `load()` |
| F-16 | 写入 `localStorage` 失败被静默捕获，内存状态继续可用，但刷新后数据丢失 | `save()` |
| F-17 | 统计数字由当前数组实时计算（`done` 计数 + `todos.length`） | `updateStats()` |
| F-18 | 列表使用 `innerHTML = ''` 后逐条重建，条目文本通过 `textContent` 写入 | `render()` |

### 2.4 样式与适配
| 编号 | 事实 | 代码位置 |
|---|---|---|
| F-19 | 使用 CSS 自定义属性定义配色（`--primary` 等），卡片圆角 + 阴影，渐变背景 | `<style>` |
| F-20 | 正文字体为 `"SimSun", "宋体", serif` | `body` |
| F-21 | 包含 `fadeIn` 关键帧动画与 `:hover` / `:active` 过渡效果 | `<style>` |
| F-22 | 仅在 `max-width: 400px` 时调整 `.app` 内边距，无其他响应式规则 | `@media` |

### 2.5 代码中**不存在**的能力（现状，非缺陷结论）
以下能力在当前代码中完全没有实现，仅作为"现状记录"，是否需要属于待确认需求：

- 编辑已有条目、批量操作、全选/清除已完成
- 筛选（全部/未完成/已完成）、排序、搜索
- 截止日期、优先级、标签、分类/多清单
- 数据导入/导出、后端同步、多设备共享、账号体系
- 撤销/重做、拖拽排序
- 任何自动化测试、构建脚本、依赖管理文件
